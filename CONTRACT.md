# Implementation ownership and contract
Package app.nottheomi.ai. Native Java 17 Android min26 target34. No network permission/PC/cloud code. Omi BLE transport is supported from 0.2.0; phone microphone remains explicit fallback. Original Omi tree read-only. From 0.3.0 Home Connect starts the existing foreground Omi capture path (after permissions/notifications); there is no separate wearable Start step, no boot/launch auto-start and no PC sync. Main screen includes partial preview, committed final log and bounded recent saved sessions; full archive stays local.

Storage lane owns Recordings.java and its own helper classes, plus RecordingsTest.java. Capture lane owns CaptureService.java, ModelInstaller.java and capture/model tests. Parent owns UI, playback, manifest/resources/build/docs/signing/integration tests. No crossing ownership without parent.

Omi recovery contract (retained from 0.3.3): an explicitly authorized foreground capture may reconnect within the 120-second no-PCM bound. Recoverable gaps are ordered controls, not authorization revocation; explicit Stop remains terminal and non-sticky. Never append resumed PCM to the same encrypted recording ID across a gap: drain earlier speech/control work within a 250 ms ASR wait budget, finalize that archive, and create a continuation only when resumed PCM is available. On speech timeout, fence all late archive/display writes, transfer pending controls exactly once in FIFO order, and keep capturing audio-only with no replacement native worker. Do not close an in-flight native owner. Final native teardown remains joined and can be unbounded. Whisper consumes eight-second batches; ASR-only queue capacity is thirty seconds and does not change BLE archive-ingress bounds. Stop stops the source immediately, allows thirty seconds of ASR drain, then requests sticky native cancellation. Only the inference owner closes native state; active remains true until owner exit. No hard upper bound is claimed for stuck native code. Append an incomplete-transcript warning to every affected segment, with no retry of an ambiguously failed warning commit. Keep earlier bookmarks/markers in their originating archive, reset speech at boundaries, preserve accepted pre-Stop PCM, and fail closed on rollover storage errors. Recording durations represent stored samples, not reconstructed wall-clock gaps. No schema migration, synthetic silence or background auto-start. Both phone-microphone and Omi services use the pinned Whisper small.en Q5_1 model from 0.4.0, with one capture source at a time.
